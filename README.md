# E-Commerce Website Manual Testing Project

## Project Overview
This project focuses on manual testing of the SauceDemo e-commerce application to verify its functionality and identify potential defects.

## Application
SauceDemo: https://www.saucedemo.com/

## Testing Type
- Manual Testing
- Functional Testing
- Positive Testing
- Negative Testing
- Validation Testing

## Modules Tested
1. Login
2. Products
3. Shopping Cart
4. Checkout
5. Order Overview
6. Order Confirmation
7. Logout

## Testing Documents
- Test Plan
- Test Scenarios
- Test Cases
- Test Execution Reports
- Bug Report Template
- Bug Investigation Report
- Final Test Summary Report

## Tools Used
- SauceDemo
- Microsoft Word
- GitHub
- Web Browser

## Skills Practised
- Manual Testing
- Test Case Design
- Test Execution
- Bug Reporting
- Functional Testing
- SDLC
- STLC

## Project Outcome
Completed selected manual testing activities across seven application modules. Six additional investigation checks were performed, with no confirmed defects identified in those checks.
